# 0002 — v1.0 scope: *E. coli* Achtman only

**Date**: 2026-08-26

**Decided**: the first public release ships one scheme pack, `ecoli_achtman`, on the multi-scheme architecture of 0003. Other organisms are added in v1.x as each is validated with its own primers and data.

**Why**: ship sooner; the only validated wet-lab primers and data are *E. coli* (Jia et al. 2024, *Poultry Science* 103:104067).

**Rejected**: multi-organism from day one — no second organism has primers or data yet.
